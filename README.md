# Mazapan's package repository

What installed Mazapan systems update from, served at https://repo.mazapan.dev:
`stable/x86_64/` and `edge/x86_64/`, each a pacman repository named `mazapan`,
every package and database signed. Written by `pkg/release` in
[rick-dev-creator/mazapan](https://github.com/rick-dev-creator/mazapan); nothing here is edited by hand.
